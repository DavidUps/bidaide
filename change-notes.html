0.2 — IntelliJ IDEA and four languages

Now also in IntelliJ IDEA

  • The same plugin installs in IntelliJ IDEA 2026.1 or later, with the whole GitHub part: pull requests, code review, issues, Actions, releases, inbox, discussions and projects.
  • What needs a device stays in Android Studio: ADB operations, installing APKs and testing a pull request on a device.
  • CI artifacts and release assets still download in IntelliJ IDEA, to a folder you choose in Settings → Tools → Bidaide → Downloads.

English, Spanish, French and Italian

  • Every menu, dialog, notification and setting is translated, and dates follow the chosen language.
  • New language setting in Settings → Tools → Bidaide: Automatic follows the IDE's language and falls back to English; or pick one of the four. Restart the IDE to see the change everywhere.
  • GitHub terms such as pull request, issue, merge or commit stay in English, as on github.com.
  • The bug report issue that ADB fills in is written in your language.

0.1 — First public release

GitHub, through the GitHub CLI you already use

  • Pull requests: list in the style of github.com, create, check out, approve, request changes, merge (with auto-merge), update branch.
  • Code review inside the IDE: inline threads in the diff viewer, pending reviews, suggestions, resolving conversations, reactions.
  • Mark files as viewed, and tick individual changes off one by one.
  • Merge requirements at a glance: approvals, required checks, conversations, conflicts, read from rulesets and branch protection.
  • Author and reviewers with their GitHub avatars.
  • Issues: list, detail, board view with drag and drop, create a branch from an issue, create an issue from a selection or a TODO.
  • Actions: runs, logs with links to your sources, re-run, cancel, workflow dispatch, download artifacts.
  • Releases, notifications inbox, discussions and project boards.
  • Test a pull request on a device: build, install and start it from a separate worktree, without touching your branch or your changes, or check it out in your copy and run it.
  • Status bar widget with the pull request of the current branch; conversation markers in the editor.
  • Open in GitHub, copy permalink, create gist, find the pull request that introduced a line, search code.

ADB, one shortcut away

  • Uninstall, kill, start, restart, clear data and cache, reinstall, install an APK, attach the debugger, grant and revoke permissions.
  • Deep links, screenshots, screen recording, logcat of your app only, send text to the device.
  • Dark mode, font scale, per-app language, animations, rotation, and device profiles that apply several settings at once.
  • Simulate airplane mode, low battery, Doze, a killed background process, GPS location and a slow network.
  • Edit SharedPreferences, browse the app's databases with SQL, save and restore the whole app state.
  • Bug report to a GitHub issue: screenshot, logcat and device details in one step.
  • Favourite operations, pinned at the top of the popup.

No tokens to configure: the plugin uses the session of gh auth login.
